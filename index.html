Historia do HTML

(Voltar)

HTML (HyperText Markup Language) é a linguagem padrão para criar e estruturar páginas web. Ela não é uma linguagem de programação, mas sim uma linguagem de marcação que define como o conteúdo de uma página, como texto, imagens e outros elementos, deve ser apresentado no navegador.

Origens e Evolução:

1991: Tim Berners-Lee cria o HTML original no CERN, com o objetivo de compartilhar documentos de pesquisa.
1993: A primeira versão do HTML, com 18 tags, é publicada.
1995: É publicada a especificação HTML 2.0, marcando o início da padronização pela W3C.
1997: Lançamento do HTML 3.2, que introduziu novas funcionalidades e corrigiu problemas de compatibilidade da versão anterior.
1999: O HTML 4.01 se torna um padrão oficial, consolidando a linguagem.
2014: O HTML5 é lançado, trazendo uma revolução no desenvolvimento web com novos elementos semânticos, suporte a multimídia (áudio e vídeo), formulários aprimorados e a capacidade de armazenamento local.

Para que serve o HTML

(Voltar)

Criação de um blog: O HTML é usado para estruturar o texto, adicionar imagens e criar links para artigos relacionados.

Construção de uma loja online: O HTML organiza produtos, descrições, preços e botões de compra.

Desenvolvimento de interfaces de usuário: O HTML define a disposição de elementos como botões, formulários e menus em aplicativos web.

Em resumo, o HTML é a linguagem essencial para a construção da web. Ele fornece a estrutura e o conteúdo básico que permite aos navegadores exibir e interagir com as páginas web.

Tags para o HTML

(Voltar)
Tags de bloco:
Ocupam toda a largura disponível do elemento pai e criam um novo bloco de conteúdo (ex: h1, p, div).
Tags em linha:
Ocupam apenas o espaço necessário para o conteúdo e não criam novos blocos (ex: span, a, img).
Tags de fechamento:
Necessitam de uma tag de abertura e uma de fechamento (ex: p.../p, div.../div).
Tags sem fechamento:
Não precisam de tag de fechamento (ex: br, img).
Exemplos de tags:
h1 a h6: Define títulos e subtítulos.
p: Define um parágrafo.
a: Cria links para outras páginas ou recursos.
img: Insere imagens na página.
ul, ol, li: Define listas não ordenadas, ordenadas e itens de lista, respectivamente.
div: Define uma divisão ou seção na página.
Ao utilizar as tags corretamente, é possível criar páginas web bem estruturadas, com conteúdo claro e significado semântico, otimizando a experiência do usuário e a indexação pelos mecanismos de busca.
